## 快速开始

```bash
# 进入任意 demo 目录
cd 001-基础入门示例

# 构建镜像
docker build -t demo-001 .

# 运行容器
docker run --rm demo-001
```

## 环境要求

- Docker 20.10+
- Docker Compose 2.0+
- 部分示例需要 Kubernetes（041, 045, 054）
- 部分示例需要 Swarm（058）
