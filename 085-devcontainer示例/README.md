# 85-devcontainer示例

VS Code Dev Container 开发环境示例。

## 使用方法

1. 用 VS Code 打开此目录
2. 按 `Ctrl+Shift+P`，输入 `Dev Containers: Reopen in Container`
3. VS Code 将在容器内打开开发环境

## 文件说明

- `.devcontainer/devcontainer.json` - DevContainer 配置
- `Dockerfile` - 开发环境镜像

## 学习要点

- DevContainer 配置
- 开发环境容器化
- VS Code 远程开发
- 端口转发
